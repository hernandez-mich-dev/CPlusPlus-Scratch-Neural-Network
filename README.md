# C-Scratch-Neural-Network
XOR Problem Solving Neural Network
A simple feedforward neural network implemented from scratch in C++ that
learns to solve the XOR problem using backpropagation and gradient
descent. 
Training is done over 100,000 epochs, after each epoch a loss function is calculated and output to the terminal. 
After training is finished, the dataset is ran through the neural network and the predicitions are output to the terminal.
The goal is for the Neural Network to predict that inputs {0, 0} and {1, 1} with a value of 0 (False). And for inputs {0, 1} and {1, 0} to be predicted 1 (True).
